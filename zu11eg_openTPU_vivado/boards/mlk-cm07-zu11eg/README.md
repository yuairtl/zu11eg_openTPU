# Milianke MLK-CM07 ZU11EG

Target device: `XCZU11EG-FFVC1760-2-i`

## DDR architecture

- Two independent PL DDR channels.
- openTPU logical bytes: 4 GiB.
- Each channel openTPU address space: 2 GiB.
- 64-byte logical beat interleave.
- CHASH enabled.
- Core native interface: 512-bit, one 64-byte beat per command.

## DDR4 implementation

- Xilinx `ddr4 v2.2` MIG x2.
- DDR4-2400.
- 64-bit per channel.
- Board BOM: `MT40A1G16TB-062E-IT-E`.
- Vivado 2025.2 MIG catalog surrogate: `MT40A1G16RC-062E`
  (same density, x16 organization and `-062E` speed grade).
- Single rank.
- ECC disabled.
- `DM_NO_DBI`.
- 300 MHz UI/AXI clock.
- 4 GiB physical address map per channel; first board uses the low 2 GiB.
- TMEM's 200 MHz pump clock is generated by an MMCM from the same 100 MHz PS PL0
  clock as the Core; PS PL1 is disabled.
- A post-configuration `DCIRESET` gates both MIG reset controllers until the DCI
  controller reports `LOCKED`.

## First board

Status: `SOURCE-AUDIT-COMPLETE / DYNAMIC-VERIFICATION-PENDING`. Existing bit/XSA/
BOOT.BIN/driver artifacts predate the latest source fixes and must not be used.
See `HARDWARE_HANDOFF.md` for the corrected review and rebuild sequence.

- Replace XDMA BAR0 with PS HPM0 AXI-Lite.
- Replace XDMA H2C/C2H with PS HP0/HP1 DMA.
- Keep the R2 console path: PL `axi_uartlite_0`, 115200 8N1. The reference R2
  pinout is `M17=RXD`, `M16=TXD`, but the current F002 PCB connects CH342K
  `TXD1` to `M16` and `RXD1` to `M17`. The first-board XDC compensates with
  `M16=UART_0_rxd`, `M17=UART_0_txd`; a PCB ECO should swap the CH342-side
  `UART_TXD_PL`/`UART_RXD_PL` connections and restore the reference pinout.
- Do not enable or infer a PS MIO UART for the console.
- Preserve the existing openTPU host AXI contract and software channel split.
- Retarget DDR3 controller implementation to the DDR4 MIG parameters above.
- Keep logical bridge, event-driven C2H and MIG UI for later stages.
